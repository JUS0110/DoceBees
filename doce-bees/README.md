## 📖 Sobre o projeto
Uma landing page desenvolvida para atender às necessidades de um negócio real, com foco em fortalecer sua presença digital, apresentar seus serviços e facilitar o contato com potenciais clientes.

Além do desenvolvimento da interface, o projeto prioriza boas práticas de desenvolvimento front-end, organização de componentes e responsividade para diferentes dispositivos.


## ✨ Funcionalidades
- Página totalmente responsiva.
- Interface moderna e intuitiva.
- Apresentação do negócio e produtos por encomenda.
- Seção de contato para captação de clientes.
  

## 📂 Estrutura do Projeto

```text
📁 src
├── 📁 assets
├── 📁 components
├── 📁 pages
├── App.jsx
├── main.jsx
└── index.css
```


## 🎯 Objetivo

Desenvolver uma landing page profissional que atenda às necessidades de um negócio real, oferecendo uma interface moderna, responsiva e capaz de comunicar sua proposta de valor, fortalecer sua presença digital e facilitar o contato com potenciais clientes.
